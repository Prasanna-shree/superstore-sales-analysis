# 📊 Superstore Sales Analysis

A comprehensive data analysis project that explores Superstore sales data using Excel, SQL, Python, Power BI, and Tableau.

## 📌 Project Overview

This project analyzes Superstore sales data to understand overall sales performance, profitability, customer segments, product categories, regional performance, shipping modes, and loss-making sub-categories.

The project transforms raw business data into meaningful insights through data cleaning, exploratory analysis, SQL queries, Python scripts, and interactive dashboards.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify high-performing categories and regions
- Analyze customer segments and product performance
- Identify loss-making sub-categories
- Perform data quality checks
- Analyze discount and profitability patterns
- Create dashboards for clear business reporting

## 📈 Key Insights

- Technology generated the highest category sales.
- The West region recorded the highest sales and profit.
- The Consumer segment generated the highest sales and profit.
- Tables was the largest loss-making sub-category.
- Bookcases and Supplies also generated negative profits.
- Standard Class recorded the highest shipping-mode activity.
- Overall business profitability should be monitored alongside sales growth.

## 💡 Recommendations

- Focus on expanding the Technology category.
- Investigate losses in Tables, Bookcases, and Supplies.
- Maintain strong performance in the West region.
- Develop strategies to improve weaker regions.
- Continue focusing on the Consumer segment.
- Review discounts, pricing, and costs for loss-making products.
- Use dashboards to regularly monitor sales and profitability.
